Definicja

Platforma orkiestracji kontenerów

Utrzymuje zadeklarowany stan aplikacji w klastrze: rozmieszcza workloady, odtwarza je po awarii, udostępnia w sieci i przeprowadza kontrolowane aktualizacje.

K8s nie buduje aplikacji ani obrazu. Zarządza uruchomieniem gotowych obrazów.

Ten sam mechanizm, różne odpowiedzialności

Kontroler, operator i Ingress Controller

Kontroler

Wbudowana pętla pilnująca konkretnego stanu, np. liczby replik.

Operator

Niestandardowy kontroler z wiedzą operacyjną o konkretnej aplikacji.

Ingress Controller

Odczytuje reguły Ingress i konfiguruje obsługę ruchu HTTP.

Każdy operator jest kontrolerem, ale nie każdy kontroler jest operatorem.

Jak to współpracuje?
  • API Server — uwierzytelnia, autoryzuje i waliduje żądania.
  • etcd — przechowuje stan klastra.
  • Scheduler — wybiera node dla Poda.
  • Kontrolery — uzgadniają stan rzeczywisty z deklaracją.
  • kubelet — na nodzie doprowadza Pody do działania.

Cel poleceńZwiększyć liczbę replik aplikacji do trzech, a następnie obserwować tworzenie nowych Podów na żywo.
kubectl scale deployment hello-k8s --replicas=3
kubectl get pods -l app=hello-k8s -w

OOM — Out Of Memory

Kontener przekroczył limit pamięci. System może zakończyć jego proces, a Kubernetes uruchomi go ponownie.

HPA — Horizontal Pod Autoscaler

Automatycznie zwiększa lub zmniejsza liczbę Podów na podstawie metryk, np. użycia CPU.

Zmiana wersji
Cel poleceńWdrożyć obraz 1.1.0, śledzić aktualizację, sprawdzić historię, a w razie problemu wycofać ostatnią zmianę.
kubectl set image deployment/hello-k8s app=hello-k8s:1.1.0
kubectl rollout status deployment/hello-k8s
kubectl rollout history deployment/hello-k8s
kubectl rollout undo deployment/hello-k8s

Readiness probe decyduje, kiedy nowa replika może wejść do ruchu.

Nie tylko Deployment

StatefulSet

DaemonSet

Job / CronJob

PVC — PersistentVolumeClaim

Żądanie trwałego miejsca na dane. Pod montuje wolumen przez PVC, dlatego może zostać odtworzony bez utraty danych zapisanych poza jego systemem plików.
