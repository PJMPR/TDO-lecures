Demo prowadzącego

ASP.NET Core + MySQL

Małe API floty kosmicznej przygotowane do demonstracji Dockerfile, sieci, wolumenu, healthcheck i Compose.

Co zawiera projekt

  • .NET 10 Minimal API i Entity Framework Core,
  • MySQL 8.4 z trwałym wolumenem,
  • CRUD statków pod /api/spaceships,
  • endpoint /health i dokument OpenAPI,
  • wieloetapowy Dockerfile uruchamiany bez uprawnień root.

Uruchomienie

cd demos/dotnet-mysql
cp .env.example .env
docker compose up --build -d
docker compose ps
docker compose logs -f api

API działa na localhost:8080, a MySQL jest dostępny dla DataGrip na localhost:3307.

Scenariusz demonstracji

  1. Uruchom sam MySQL poleceniem docker run.
  2. Połącz DataGrip z opublikowanym portem.
  3. Zbuduj obraz API i pokaż warstwy.
  4. Uruchom API w tej samej sieci i wyjaśnij, dlaczego hostem jest nazwa bazy.
  5. Usuń kontenery, zachowując wolumen.
  6. Odtwórz cały układ przez Compose.
  7. Pokaż healthcheck, logi, exec i inspect.
